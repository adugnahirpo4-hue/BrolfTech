# BrolfTech

A static, multi-page e-commerce storefront and admin template built with HTML, CSS, and JavaScript.

## Project structure

```text
.
├── index.html                 # Storefront home page
├── about.html                 # Storefront pages
├── account.html
├── cart.html
├── change-password.html
├── checkout.html
├── contact.html
├── orders.html
├── product.html
├── refund.html
├── shop.html
├── terms.html
├── admin/                     # Admin pages and admin-specific styles
│   ├── css/
│   └── *.html
└── assets/
    ├── css/                   # Storefront styles
    ├── fonts/                 # Roboto font files
    ├── images/                # Icons, product, slider, and other images
    ├── js/                    # Site scripts and jQuery
    └── vendor/                # Third-party libraries (FancyBox)
```

## Run locally

Open `index.html` in a browser, or serve the project directory with a local static web server. The storefront pages remain at the repository root so their existing links and GitHub Pages URLs continue to work.
